# Frontend File Naming Convention

All new files created inside `frontend/src/components/` and its subfolders (atoms, molecules, organisms, layout, templates), as well as `frontend/src/pages/`, `frontend/src/contexts/`, `frontend/src/services/`, and `frontend/src/styles/` must start with a lowercase letter.

Examples:
- `button.tsx` ✅
- `Button.tsx` ❌
- `heroSection.tsx` ✅
- `HeroSection.tsx` ❌
- `authContext.tsx` ✅
- `AuthContext.tsx` ❌
