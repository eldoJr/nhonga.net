## Overview

**Nhonga** is an all-in-one platform designed for the Mozambican market, combining professional networking, job recruitment, freelance services, B2B connections, and academic opportunities into a single ecosystem.

## Core Modules

| Module | Description |
|--------|-------------|
| **Professional Network** | Detailed profiles, CVs, endorsements, skills, and industry discussion groups |
| **Jobs & Recruitment** | Job posting & search, application tracking, vacancy alerts, recruiter tools |
| **Services Marketplace** | Service catalog, quotes, portfolios, ratings, and payments for freelancers |
| **B2B Network** | Company profiles, partner search, business opportunities (suppliers, investors) |
| **Academic Portal** | Scholarships, courses, internships, training programs, and application deadlines |
| **Career Development** | Articles, webinars, online courses, and professional growth content |

## Tech Stack

```
Frontend    React 19 · TypeScript · Tailwind CSS · Vite · Framer Motion
Backend     Node.js · Express (planned)
Database    PostgreSQL (planned)
```

## Getting Started

```bash
# Clone
git clone https://github.com/your-org/nhonga.net-1.git
cd nhonga.net-1/frontend

# Install dependencies
npm install

# Development server
npm run dev

# Production build
npm run build
```
